### Key Route Highlights:
- Address `0x28`: `main` calls `<pause>` at address `0x356`.
- Address `0x356`: `<pause>` loads immediate value `13` (which is `SYS_pause` from `kernel/syscall.h`) into register `a7`.
- Address `0x358`: executes `ecall` (`00000073`). This instruction transitions the hardware CPU from User mode (U-mode) into Supervisor mode (S-mode) and vectors into `kernel/trampoline.S`.

## 4. Native Linux Comparison Trace

To observe the general concept of user-to-kernel sleep crossing on native Linux:

```bash
strace -e trace=nanosleep,clock_nanosleep sleep 1
```

Observed output on Linux x86-64 (glibc 2.39):
```text
clock_nanosleep(CLOCK_REALTIME, 0, {tv_sec=1, tv_nsec=0}, NULL) = 0
+++ exited with 0 +++
```

> **Observation:** Modern Linux implements `sleep` via `clock_nanosleep` or `nanosleep`. Like xv6's `pause`, the user-space libc wrapper executes an architecture syscall instruction (`syscall` on x86-64), placing the process onto the kernel's timer wait queue until the hardware timer interrupt fires.
