# Essential CS

Essential CS is a rigorous, self-study-first computer science curriculum for learners with basic programming experience but no formal CS background.

Its goal is not to compress a four-year degree, maximize implementation, or train on fashionable products. The goal is to build an accurate modern computing-system world model and the ability to trace, explain, observe, diagnose, reason about correctness, judge trade-offs, estimate scale/cost, and independently learn unfamiliar technologies.

## Current phase

**Curriculum Blueprint v0.1**

The project is currently establishing curriculum architecture, research standards, lab policy, review gates, multi-agent collaboration, and the complete Core learning map before large-scale lesson writing begins.
