# Licensing

Essential CS uses a dual licensing strategy for original project work.

## Educational content

Original curriculum text, original educational diagrams, and original curriculum design are intended to be licensed under **Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)**.

## Code

Original source code, tools, lab code, and the Mini Cloud App are intended to be licensed under **Apache License 2.0**.

## Third-party material

Third-party works retain their own licenses. Their use, adaptation, and attribution must be recorded in provenance and `ATTRIBUTION.md`.

Before the first public content/code release, add the canonical full license texts and verify file-level/source-level notices where appropriate.
