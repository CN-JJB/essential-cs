# Licensing

Essential CS uses a dual licensing strategy for original project work.

## Educational content

Original curriculum text, original educational diagrams, and original curriculum design are licensed under **Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)**.

Canonical full text: [`LICENSES/CC-BY-SA-4.0.txt`](CC-BY-SA-4.0.txt)

Verified against the official Creative Commons plaintext legal code:
`https://creativecommons.org/licenses/by-sa/4.0/legalcode.txt`

## Code

Original source code, tools, lab code, and the Mini Cloud App are licensed under **Apache License 2.0**.

Canonical full text: [`LICENSES/Apache-2.0.txt`](Apache-2.0.txt)

Verified against the official Apache Software Foundation text:
`https://www.apache.org/licenses/LICENSE-2.0.txt`

## Third-party material

Third-party works retain their own licenses. Their use, adaptation, and attribution must be recorded in provenance and `ATTRIBUTION.md`.

File-level/source-level notices may still be added where appropriate. The canonical project license texts themselves are now committed in this directory.
