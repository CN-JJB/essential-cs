# Concept Registry

Status: **Initial structure only**

The Concept Registry is stricter than a glossary. It prevents canonical definitions from drifting across modules.

## Entry schema

Each stable concept should eventually record:

- `id`
- canonical Chinese name
- canonical English name
- canonical definition
- first-introduced location
- canonical lesson
- related concepts
- common confusions
- Big Ideas
- context qualifiers where the same English word is overloaded

## Canonical explanation rule

**Teach once, revisit many times.**

A concept's core definition/mechanism should have one primary teaching location. Other lessons/labs/projects may include short recap and context-specific application, but should not silently fork the canonical explanation.
