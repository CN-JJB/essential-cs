## Use

The Web Lead should match Task Prompts to actual agent capabilities when the user provides them.

Typical roles:

- Research Agent
- Curriculum/Design Agent
- Writer Agent
- Lab Agent
- Verification Agent
- Maintenance Agent
- Reviewer Agent

Do not assume every Local AI has equivalent web research, shell, browser, code execution, repository editing, or long-form writing capabilities.
