# Student Route Acceptance Checklist

Checked: 2026-09-12

A first-time learner should be able to start at the root `README.md`, enter `LEARNING_ROADMAP.md`, choose the next module from the M00–M24 index, and for every module answer four questions without searching the repository blindly:

1. **What exactly am I learning?** — the module lists concrete knowledge points, not only a broad subject name.
2. **What exactly should I read/watch?** — each knowledge point maps to a specific chapter, lecture, RFC section, manual page, or official documentation page.
3. **How deep do I need to go now?** — `Core`, `Reference`, and `Optional deep dive` are separated; whole-course completion is never implied when only a subset is needed.
4. **How do I know I can move on?** — every module has a short checkpoint / exit condition and a direct link to the next module.

## Navigation acceptance

- Root entry: `README.md` → `LEARNING_ROADMAP.md`.
- Roadmap has a one-click M00–M24 index grouped by S1–S7.
- Every module links to its repo lesson directory as an orientation/synthesis companion.
- Every module ends with an explicit `Next` link.
- External resources are named by the exact subset to use (lecture/chapter/section/page), not merely by course/book title.
- Learners are explicitly told what **not** to finish when a source is much larger than the Core need.

## Resource acceptance

Prefer, in order:

1. current standards / official documentation for protocols and product behavior;
2. established university course lectures or free authoritative textbooks for stable mechanisms;
3. high-quality practitioner references for operational judgement;
4. repo-owned lessons for orientation, synthesis, and Chinese-language connective explanation.

A resource entry is insufficient if it only says “take Course X”, “read Book Y”, or “read the docs” without naming the relevant subset.

## Scope

This checklist validates route clarity and resource specificity. It does not require every learner to run repo-owned Labs or Mini Cloud. Those remain optional companions under `meta/RESOURCE_FIRST_CURRICULUM_POLICY.md`.
